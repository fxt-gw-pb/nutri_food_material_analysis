# 上线准备：买服务器、买域名、办个人 ICP 备案

> 2026-11-27 整理。价格和流程细节来自阿里云、腾讯云帮助中心及第三方文章，**下单与提交前以官网页面为准**。完成本文后，接着按 [网页版说明 · 部署上线](web-version.md#部署上线) 操作。

## 总览

| 步骤 | 你要做的 | 等待时间 |
| --- | --- | --- |
| 1 | 买国内轻量应用服务器（≥3 个月，建议 1 年） | 当天 |
| 2 | 买域名，用本人身份证完成域名实名 | 1–3 天审核 + 2–3 天同步到工信部 |
| 3 | 提交个人 ICP 备案（含人脸核验、短信核验） | 服务商初审 1–2 个工作日，管局审核最长约 20 个工作日 |
| 4 | 备案通过后部署网页版、申请 HTTPS | 约 1 小时 |
| 5 | 上线 30 日内办公安联网备案 | 约 1 周 |

从下单到可用，通常 **3–5 周**，主要耗在管局审核。备案期间网站必须保持关闭，但可以继续在本地用 `npm run web:dev` 试用。

## 0. 选哪家：建议阿里云

阿里云和腾讯云的轻量应用服务器都能备案，价格接近。建议选**阿里云**：千问 API Key 本来就在阿里云账号下，这个账号已经实名认证，服务器、域名、备案、API Key 在同一个账号里管理，备案时系统会自动关联服务器，不用另外申请备案服务号。

下文以阿里云为例；腾讯云流程基本相同（入口叫「ICP 备案」控制台）。

## 1. 买轻量应用服务器

1. 登录阿里云（用有千问 Key 的那个账号），进入「轻量应用服务器」购买页。
2. 选择：
   - **地域**：中国内地任意地域，如华北 2（北京）、华东 1（杭州）、华东 2（上海）。**不要选中国香港或海外**——那些不能用于本方案的 ICP 备案。
   - **镜像**：选「系统镜像 → Ubuntu 24.04」（22.04 也可）。不要选宝塔、WordPress 等应用镜像，部署脚本是按纯 Ubuntu 写的。
   - **套餐**：2 核 2G、40 GB 云盘即可（照片压缩后每张约 0.4 MB，40 GB 能存几万张）。
   - **购买时长**：**至少 3 个月**（低于 3 个月不能用于备案，续费可累计）。新用户活动价通常是年付，建议直接买 1 年。
3. 价格参考（2026 年 11 月，仅限新用户首单，续费更贵）：阿里云 2 核 2G 约 38–68 元/年（38 元为限量秒杀），腾讯云约 68–99 元/年。
4. 买完后在控制台：
   - 记下**公网 IP**；
   - 「远程连接 / 密钥」处设置 root 或 ubuntu 账号的登录密码，或绑定 SSH 密钥（推荐密钥）；
   - 「防火墙」里确认放行 **22、80、443** 端口。
5. 先不用装任何东西。备案通过后再运行部署脚本。

## 2. 买域名并实名

1. 在阿里云「域名注册」搜索并购买域名。
   - **后缀**：选 `.cn`、`.com`、`.net` 这类常见后缀。部分后缀（如 `.io`、`.ai`）不能在国内备案，不要买。
   - **名字**：短、好念，避免地名、「中国」等字样。
2. 购买时选择/新建**个人**信息模板，持有人填**你本人**，用本人身份证完成**域名实名认证**。
   - 备案要求：域名持有人姓名、证件类型、证件号码必须与备案主体（你本人）完全一致。这是最常见的驳回原因。
3. 实名认证通过后，**再等 2–3 天**让信息同步到工信部系统，然后再提交备案。

## 3. 提交个人 ICP 备案

入口：阿里云控制台搜索「ICP 备案」，选「首次备案」。

### 3.1 主体信息（个人）

- 主体性质：个人；证件：居民身份证。
- 备案省份按**身份证所在省份**；如果长期在其他省份居住，需要提供该省的居住证，才能在居住地备案。
- 手机号、应急联系电话要能接通。管局和服务商可能会打电话核实，接不通会被退回。

### 3.2 网站信息

- **网站名称**：用能看出内容的具体名称，例如「某某的饮食记录」。注意：
  - 不能用「平台」「系统」「公司」「工作室」「商城」「社区」「论坛」「官方」「中国」及地名等字样；
  - 含人名时必须是你本人的姓名；
  - 不要用「个人博客」「个人空间」这类过于笼统的名称；
  - 与网页版首页标题保持一致。上线后把服务器配置里的 `SITE_TITLE` 改成这个名称。
- **网站内容 / 备注**：如实、具体地写，例如：「个人非经营性饮食记录工具，仅供本人及受邀亲友记录饮食照片和食用情况，不对外开放注册，无论坛、评论等公开交互功能」。
- **前置审批**：无。网站只做饮食记录，页面已注明不构成医学建议；不要在名称或备注里写「医疗」「诊断」「健康咨询」之类的词。
- **个人备案只能用于非经营性网站**：不收费、不做广告、不卖东西。

### 3.3 核验与审核

1. 上传身份证正反面，按提示在**阿里云 App** 完成人脸核验（个别省份，如上海，要用当地通信管理局的 App）。
2. **服务商初审**：约 1–2 个工作日，可能来电核实信息。
3. **工信部短信核验**：收到短信后 **24 小时内**按短信提示登录工信部系统完成验证，超时要重新提交。
4. **管局审核**：通常最长约 20 个工作日，省份不同差异较大。通过后会收到备案号，形如「京ICP备2026xxxxxx号-1」。

### 3.4 备案期间注意

- 法规要求首次备案期间**网站处于关闭状态**：不要部署、不要把域名解析到有内容的服务器上。
- 被驳回时按驳回原因修改再提交即可，常见原因是网站名称不合规、域名实名信息不一致、电话打不通。

## 4. 备案通过后上线

1. 在阿里云「云解析 DNS」给域名加一条 **A 记录**：主机记录 `@`（如需 www 再加一条 `www`），记录值填服务器公网 IP。
2. 按 [网页版说明 · 部署上线](web-version.md#部署上线) 运行初始化、上传和 HTTPS 申请命令。
3. 在服务器 `/etc/food-web.env` 填上 `ICP_NUMBER`（备案号），重启服务。网站首页和登录页底部会显示备案号并链接到工信部系统，这是备案网站的强制要求。
4. 用 `sudo food-web-admin sheet 编号1 编号2 …` 生成参与者二维码，用手机微信扫码确认能打开。

## 5. 上线 30 日内：公安联网备案

1. 打开全国互联网安全管理服务平台 `https://beian.mps.gov.cn/`，以个人身份注册并实名。
2. 「新办网站申请」，填网站信息（与 ICP 备案一致），负责人选「同主体负责人」。
3. 公安机关审核，通常约一周，期间可能电话联系。
4. 通过后把公安备案号填进 `/etc/food-web.env` 的 `PSB_NUMBER`，重启服务即可显示在页面底部。

## 6. 合规提醒

- **保持封闭访问**：网页只给受邀参与者和调研员使用（口令 + 专属链接），不要放开注册或匿名使用。这也是本方案避开「向公众提供生成式 AI 服务」的前提。
- **AI 生成内容标识**：《人工智能生成合成内容标识办法》自 2025 年 9 月 1 日起施行，要求对 AI 生成合成内容添加用户能明显看到的标识。网页版的菜名和食材都由千问识别产生，建议在识别结果处注明「由 AI 识别，仅供参考」（目前页面只写了「识别结果」和估算免责声明，尚待补充）。
- 服务器上保存有参与者照片和饮食记录，定期把 `/var/backups/food-web` 下载到自己电脑，或开启云服务商快照。
